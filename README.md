# 超市小票分析器 · 你的购物车暴露了什么？

> 上传一张超市小票，AI 不只告诉你买了什么，还要大胆猜猜你是一个什么样的人。

## 项目简介

「超市小票分析器」是一个趣味性的购物人格分析 Web 应用。用户上传一张超市购物小票照片，应用会模拟 OCR 识别出商品清单，然后基于购物品类、消费结构、单品均价等维度，用规则引擎分析出用户的「购物人格」，并生成一份可分享的人格报告。

这是一个 MVP（最小可行产品）级别的 Vibe Coding 项目，核心目标是：**用最简单的方式，给用户一个"被看穿"的趣味体验。**

## 核心功能

- 📸 **小票上传** — 支持拍照或从相册选择图片（JPG/PNG）
- 🔍 **模拟 OCR 识别** — 动画展示识别过程，生成随机但合理的购物清单
- ✏️ **清单确认与编辑** — 用户可修改商品名称、价格、数量、品类，增删条目
- 🧠 **六维人格分析** — 健康指数、效率指数、享乐指数、精打细算、顾家指数、仪式感
- 🎭 **九种人格原型** — 自律美食家、效率至上主义者、快乐至上派、精致生活家、家庭大厨、囤货达人、快乐水信徒、超级奶爸/辣妈、随性购物者
- 📊 **可视化报告** — 雷达图 + 评分条 + 品类分布 + AI 观察 + 个性化建议
- 📱 **可分享人格卡片** — 生成适合社交分享的摘要卡片
- 🗂️ **历史记录** — 本地保存所有分析报告，随时回看

## 人格分析逻辑

### 六大维度评分（0-100 分）

| 维度 | 说明 | 计算依据 |
|------|------|----------|
| 🥬 健康指数 | 生鲜、蛋白质占比 | 生鲜+蛋白质金额加权，零食/速食扣分 |
| ⚡ 效率指数 | 速食、即食偏好 | 速食金额 + 零食数量加权 |
| 🍫 享乐指数 | 零食、甜品、饮料 | 零食+甜品+饮料金额加权 |
| 💰 精打细算 | 单品均价、日用品 | 单品均价越低分越高 |
| 🏠 顾家指数 | 母婴、日用、做饭食材 | 母婴+日用+蛋白质+商品数量 |
| ✨ 仪式感 | 甜品、精品饮品、进口食材 | 甜品+饮品+生鲜加权 |

### 九种人格原型

系统根据各品类金额占比和维度评分，匹配最符合的人格原型，每种原型配有专属描述和贴心建议。

## 设计特色

- **小票纸张质感** — 使用 CSS 渐变 + 锯齿边缘模拟真实收据纸
- **暖色调色系** — 以米黄（paper）、墨黑（ink）、橙（accent）为主色，营造温暖手作感
- **微交互动画** — 扫描线、脉冲环、摇摆图标、逐项浮入等细节
- **移动优先** — max-w-md 居中布局，适配手机竖屏体验
- **中文字体** — 标题用 ZCOOL KuaiLe（手写体），正文用 Noto Sans SC
